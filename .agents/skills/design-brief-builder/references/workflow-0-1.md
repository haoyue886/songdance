# 新建设计规范

已有设计决定直接吸收，未知维度再分析。不要求先完成固定采访阶段。

1. **确定目标和载体**：从需求、现有产品和用户材料识别核心任务、受众、界面/终端/会话等形态以及实际目标设备。
2. **复用约束**：提取已有品牌、设计稿、组件库、参考与用户明确偏好。只有缺少会影响整体方向的选择时才问。
3. **形成方向**：把抽象偏好转成空间、密度、排版、颜色、交互反馈等可执行属性。可提出合理默认；参考与反参考只在确有帮助时加入。
4. **覆盖核心体验**：图形界面梳理信息架构、页面、组件和适用状态；终端关注列宽与输出；Agent 补运行态、控制入口与动作记录。根据产品组合处理，不强制单轨。
5. **写入并自检**：裁剪 [设计模板](../templates/design-brief-template.md)，核对核心需求覆盖和内部一致性。

## 完成标准

- 设计目标、核心结构、主要视觉属性和交互状态足以支持本次范围内出稿或实现。
- 方向有依据，合理默认与待验证项清楚；没有把抽象词当成精确规格，也没有伪造品牌偏好。
- 与 Product Spec 的范围一致；跨文档引用只在需要追踪时使用，沿用已有编号。
- 无关设备、形态和状态章节删除，避免为了填表扩张需求。

可以用简短摘要让用户及时纠正关键假设，不以“用户点头”作为每步的固定出口。后续环节已获授权时持续推进。
