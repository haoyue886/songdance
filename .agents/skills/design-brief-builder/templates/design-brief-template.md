# Design Brief 模板

按产品形态与本次设计范围裁剪。已有 Brief 只更新受影响部分；无关章节删除。需求可以来自 Spec 或用户明确要求，不因模板存在而扩张功能。

花括号是填写提示，交付时替换。视觉值可沿用现有设计系统或采用合理默认，重要假设单列；不要求为每个 token 询问用户。SCREEN / CMP 编号仅在跨文档引用有用时使用，保留已有编号。
