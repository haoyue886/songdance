# 需求变更记录模板

沿用项目现有变更记录方式。仅记录实质需求、行为或范围变化；文案修辞、排版修正和不影响契约的实现细节不必新增记录。已有版本方案继续使用，没有版本约定时用日期即可，不自动递增版本号。

```markdown
# 需求变更记录

## {{实际日期，YYYY-MM-DD}} — {{本次变化}}

- 变更：{{新增、修改或移除的内容，写清变化前后}}
- 原因：{{用户要求或已验证的问题；必要时填写}}
- 影响：{{受影响需求编号、流程、设计或计划；必要时填写}}
```

一条记录对应一个可理解的变化。新增 UI 控件写清位置与作用，数值变化写前后值，未发生的变化不记录。
