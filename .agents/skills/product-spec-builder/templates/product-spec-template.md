# Product Spec 模板

用于新建需求文档，按本次范围裁剪。已有文档沿用原结构；无关章节删除，不用空表或占位文字撑完整度。编号在跨文档追踪有用时采用，已有编号保持稳定。

以下花括号是填写提示，交付时替换为实际内容。合理默认写入假设，真正未知写清影响与解决方式；只把阻塞执行的事项留给用户决定。
