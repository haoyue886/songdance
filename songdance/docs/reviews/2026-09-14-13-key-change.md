# 13-key-change 专业评审记录

老师确认本段是六个音一组的均匀单旋律循环 `do-mi-sol-do-sol-mi`。4/4 无法整除该循环，导致第二轮循环落在小节中间；记谱应使用 3/4（或等价的 6/8），本专项采用 3/4。

原结果还把泛音和延音残留叠成多个同时响的音，错误生成和弦及额外声部。专项上下文固定每个八分音符槽最多一个高音事件，并使用单高音谱表，保留原始模型事件用于审计。

验证结果：使用真实 `13-key-change.wav` 跑 Basic Pitch、音尾清理、谐波证据和评分流程，原始事件 156 个，清理后 119 个，最终记谱 60 个；记谱为 60 BPM、3/4、单高音谱表，`chord_count=0`、`voice_count=0`。前 18 个起音按 0.5 秒排列并匹配六音循环。谐波证据拒绝 33 个泛音候选和 16 个非独立起音。专项 Stage 1/2 审查通过。
