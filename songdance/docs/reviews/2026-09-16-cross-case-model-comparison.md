# 两种模型的跨音源同输入对照

对06/07/14两种音源共6份此前Transkun已处理的padded.wav重新运行当前Basic Pitch生产阈值原始推理。逐组验证输入SHA相同，统一前后1秒静音与10ms首音映射容差、50/100ms起音评价；不删音、不套教师模板。原始Basic时间线和MIDI保留，参考同刻同键去重仅用于评价。

下表为50ms，三元组是匹配/额外/漏音：

100ms全量结果保存在报告中，不能用当前表替代它。Transkun在6组中5组F1更高，但06原音源漏15个真音仍是严重局限；07替代音源Basic更好。模型优劣不能简化成“专用模型全面正确”。替代音源下14两者均有误音，以上数字不能证明两者误音具有完全相同的机制。

结论：继续保留Transkun研究候选有数据支持；不替换生产、不按参考择优路由、不用Basic与Transkun全并集补音。下一步以漏音/误音分别设验收，覆盖真实录音及弱低音反例，不继续围绕单条样本的总分调参。教师已通过的07和10右手、原始录音及最终评审包不在本轮修改范围。
