# 15误音核验：默认泛音删除规则不准入

对绑定的15原始Basic MIDI237事件（原秒时间、未量化）执行现有extract_harmonic_evidence，仅采用removals，不把observations当删除许可。由于MIDI没有模型置信度，NoteEvent数值confidence为velocity/127占位，不能解释为校准概率；本次比较的是既有事件假设的音频判据，不是重新模型推理。

原音频选中0项删除：118正确起音、119额外、0漏音保持。实际写入原MIDI或候选的删除为0。

控制波形共15个：4个音区×3种上音幅度（0为纯泛音，.04/.16含独立上八度）共12个，加3个真实同音弱重击。原始声学合成明确叠加独立高音，事件由控制定义，不由模型推理。默认判据误选D4/E4/G4对应弱上八度（幅度.04）共3个真音；其他12个控制没有真音删除。同音弱重击3例没有误删，但不足以证明各种短弱重击均安全。

结论unsafe_on_controls：不能将该默认判据直接扩到15，更不能放宽阈值追求删掉119个额外音。此轮否决一个候选方案，不是泛音已修复。现有生产算法本身的真弱八度风险也由此记录，但本轮未改变生产行为或隐式扩展修复范围。
